## Question 1

Sarah is a data scientist at a mid-sized company. She wants to implement a model that can handle multiple NLP tasks with minimal labeled data. Which approach should she consider using?

- Training a separate model for each task
- ✅ Using a foundation model with tuning
- Developing a rule-based system
- Using a small dataset to train a new model from scratch

**Result:** 1 / 1 point
**Feedback:** Foundation models can be tuned with minimal labeled data to perform various NLP tasks.

## Question 2

Which of the following best describes the Natural Language Understanding (NLU) process in Natural Language Processing (NLP)?

- Generating human-like responses to text inputs
- Converting structured data into unstructured text
- ✅ Translating unstructured text into structured data
- Analyzing the grammatical structure of sentences

**Result:** 1 / 1 point
**Feedback:** This correctly describes NLU, which involves converting unstructured text into structured data.

## Question 3

A company wants to implement a system to predict customer behavior patterns using past data. Which AI approach should they focus on?

- ✅ Machine learning
- Rule-based AI
- Expert systems
- Generative AI

**Result:** 1 / 1 point
**Feedback:** Machine learning is ideal for this scenario as it excels at identifying patterns in data and making predictions.

## Question 4

How do discriminative and generative models fundamentally differ in how they learn from data?

- Discriminative models handle unsupervised learning, while generative models require labeled data.
- ✅ Discriminative models focus on decision boundaries, while generative models model data distributions.
- Discriminative models copy data patterns, while generative models ignore structure.
- Discriminative models generate new outputs, while generative models narrow down categories.

**Result:** 1 / 1 point
**Feedback:** Discriminative models learn boundaries between classes, while generative models learn how data is distributed.

## Question 5

Emma must implement a Natural Language Processing system to convert spoken language into structured data. Which process within NLP primarily translates spoken or written text into a structured format?

- Tokenization
- Named Entity Recognition
- ✅ Natural Language Understanding (NLU)
- Natural Language Generation (NLG)

**Result:** 1 / 1 point
**Feedback:** NLU is responsible for converting unstructured text into a structured format that computers can understand.
